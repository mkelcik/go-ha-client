# Code of Conduct

## Our Standards

To build a welcoming community, participants are expected to:
- be respectful and constructive
- assume good intent and give actionable feedback
- focus on the code and ideas, not personal attacks
- avoid harassment, discrimination, or abusive language

## Scope

This Code of Conduct applies to project spaces, including issues, pull requests, discussions, and other community interactions.

## Enforcement

If you experience or witness unacceptable behavior, contact:
`michal.kelcik+go-ha-client-coc@proton.me`

Maintainers may remove, edit, or reject comments and contributions that violate this Code of Conduct, and may take temporary or permanent moderation actions.
