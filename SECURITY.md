# Security Policy

Thanks for helping keep `go-ha-client` secure.

## Supported versions

Only the latest `v2` branch is currently supported with security fixes.

| Version | Supported |
| --- | --- |
| `v2.x` | :white_check_mark: |
| `< v2.0.0` | :x: |

## Reporting a vulnerability

Please do not open public issues for security vulnerabilities.

Instead, report privately by email to: `michal.kelcik+go-ha-client-security@proton.me`

Include:
- affected version
- clear reproduction steps
- expected impact
- optional fix suggestion

I will acknowledge the report within 5 business days and share a remediation plan or next steps.
